## Run Automatic Evaluation (Phase C)

```powershell
java -jar dist/irqualityevaluator.jar --index <path_to_index_dir> --topics <path_to_topics.xml> --qrels <path_to_qrels.txt> --results <path_to_results.txt> --eval <path_to_eval_results.txt> --run-name runA --use-summary true --include-topic-type true --stop-en <path_to_stopwordsEn.txt> --stop-gr <path_to_stopwordsGr.txt>
```

## Notes
- `results.txt` is produced in TREC-like format per topic.
- `eval_results.txt` is produced with per-topic metrics (`bpref`, `AveP'`, `NDCG'`).
